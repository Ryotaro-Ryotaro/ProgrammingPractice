## まず3つの演算の意味


ビット演算は、数を2進数で書いたときに、**同じ位どうしで計算**します。

| 演算子 | 名前 | 1になる条件 | 例：`12`（1100）と `10`（1010） |
|---|---|---|---|
| `&` | AND | 両方とも1 | `1100 & 1010 = 1000` → **8** |
| `\|` | OR | どちらかが1 | `1100 \| 1010 = 1110` → **14** |
| `^` | XOR | 片方だけが1（2つが違う） | `1100 ^ 1010 = 0110` → **6** |

```python
print(12 & 10)   # 8
print(12 | 10)   # 14
print(12 ^ 10)   # 6
```

セットでよく使うのが、ビットを左右にずらすシフト演算です。

```python
1 << 3    # 1 を左に3桁ずらす → 1000（2進数）= 8（2の3乗と同じ）
13 >> 2   # 1101 を右に2桁ずらす → 11（2進数）= 3
```

## 活用例

### 1. 特定の桁が1かどうか調べる（`&`）

前回の2進数変換の問題は、これを使うと短く書けます。

```python
N = int(input())
for x in range(9, -1, -1):
    print((N >> x) & 1, end="")   # x桁目を一番右までずらし、& 1 でその1桁だけ取り出す
print()
```

偶数か奇数かの判定にも使えます。

```python
if n & 1:          # 一番下の桁が1なら奇数
    print("odd")
```

### 2. ビット全探索（`&` と `<<`）：競プロで一番よく使う

「N 個のものそれぞれを、選ぶか選ばないか」という 2^N 通りを、0 から 2^N - 1 までの整数で表して全部調べる方法です。

```python
# 例：カードの中から何枚か選んで、合計がちょうど K になる選び方はあるか
A = [3, 5, 7]
K = 10
N = len(A)

for mask in range(1 << N):           # 0〜7（000〜111）
    total = 0
    for i in range(N):
        if mask & (1 << i):          # mask の i 桁目が1なら、i 番目のカードを選ぶ
            total += A[i]
    if total == K:
        print("Yes", bin(mask))      # mask = 101 → 3 + 7 = 10
```

`mask = 101`（2進数）なら、「0番目と2番目を選び、1番目は選ばない」という意味になります。鉄則本でも、この後のほうで出てくる重要な考え方です。

### 3. 集合として使う（`&` `|` `^`）

各ビットを「その要素が入っているかどうか」と見なすと、集合の演算になります。

```python
a = 0b0110   # {1, 2}
b = 0b0011   # {0, 1}

print(bin(a & b))   # 0b10   → {1}       共通部分
print(bin(a | b))   # 0b111  → {0, 1, 2} 和集合
print(bin(a ^ b))   # 0b101  → {0, 2}    片方にだけあるもの
```

ファイルの権限（読み取り・書き込み・実行）のように、複数のON/OFFを1つの数字にまとめる「フラグ」も同じ考え方です。

### 4. XOR の性質を使う（`^`）

XOR には、`x ^ x = 0`（同じものどうしは打ち消し合う）と、`x ^ 0 = x` という性質があります。

```python
# 1つだけペアになっていない数を探す
nums = [4, 1, 2, 1, 2]
ans = 0
for x in nums:
    ans ^= x
print(ans)   # 4（ペアの 1 と 2 は打ち消し合って消える）
```

```python
# ON/OFF の切り替え
flag = 0
flag ^= 1    # 1（ON）
flag ^= 1    # 0（OFF）
```

## 利点

- **組み合わせを整数1つで表せる**：ビット全探索やビットDPでは、「どれを選んだか」を整数1つで扱えます。リストより書きやすく、扱いも楽です。
- **集合の演算が1回の計算で済む**：共通部分や和集合が、`&` や `|` の1回で求まります。
- **省メモリ**：ON/OFF を何十個も、整数1つに詰め込めます。
- **速い**：CPUが直接実行できる基本的な演算です。ただし、Pythonではこの利点は小さめです（下の不利点を参照）。

## 不利点・注意点

- **読みにくい**：`mask & (1 << i)` のような式は、慣れていないと意図が分かりません。チーム開発では、コメントを付けるか、普通の書き方を選ぶほうがよい場合もあります。
- **Pythonでは速さの差が小さい**：Pythonの整数はC言語などとは仕組みが違うので、`n % 2` と `n & 1` の差はほとんどありません。速さより読みやすさを優先して大丈夫です。
- **演算子の優先順位の落とし穴（重要）**：`&` は `==` より後に計算されます。

  ```python
  if n & 1 == 0:      # ✗ n & (1 == 0) → n & False と解釈されて、常に0になる
  if (n & 1) == 0:    # ○ 括弧を付ける
  ```

- **`^` はべき乗ではない**：数学では `2^3` と書きますが、Pythonの `2 ^ 3` は XOR なので `1` になります。べき乗は `2 ** 3` です。前回の `*` と `**` の違いと合わせて覚えておきましょう。
- **`~`（ビット反転）は直感に反する**：`~5` は `-6` になります。Pythonの整数には桁数の上限がないためです。初めのうちは使わなくて大丈夫です。
